This repository contains the data for the publication submitted by
B.S. Patel et al "Sensitivities of electron scale core transport in
MAST Upgrade" 2026 [Submitted to Journal]

The CGYRO input files for two MAST-U discharges at two times are
contained in this repo, taking from TRANSP runs and generated using
pyrokinetics.

The first shot is 48640 with the corresponding TRANSP run 48640Q04
where the inputs files at created at two times; 300ms and 600ms.
Several flux surfaces from 0.3 to 0.8 have been generated and this can
be found in the directory 48640Q04 under their respective times.

The second shot is 48657 with the corresponding TRANSP run 48657Q06
where the inputs files at created at two times; 531ms and 800ms.
Several flux surfaces from 0.4 to 0.8 have been generated and this can
be found in the directory 48657Q06 under their respective times.
